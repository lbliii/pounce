## Highlights

- **Public error exports** — `PounceError`, `LifespanError`, `TLSError`, `SupervisorError`, and `ReloadError` are now available from the top-level `pounce` package. Downstream packages like chirp no longer need to import from the private `pounce._errors` module.

## Added

- Re-export `PounceError`, `LifespanError`, `TLSError`, `SupervisorError`, `ReloadError` in `pounce.__init__` and `__all__`

## Install

```bash
uv add "bengal-pounce==0.3.1"
```
