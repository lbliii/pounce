Added an opt-in, bounded, mtime-validated stat cache for the static-file hot path (`StaticMount(stat_cache=True, stat_cache_size=...)`). When enabled, a repeated request revalidates the resolved file with a single `stat()` instead of re-running path resolution, `lstat()`, and the precompressed probes, and invalidates automatically when the file changes (e.g. an SSG rebuild). Default off; path-traversal and symlink defenses still run on every cache miss/insert.
