The default `--reload` watch set now covers static-site authoring files — `.md`, `.html`, `.css`, `.js`, and `.svg` — in addition to Python and config sources, so editing content, templates, or styles triggers a reload without `--reload-include`. The watcher also scans the directories behind configured `static_files` mounts, so assets served from outside the working directory reload too. `.py` watching is unchanged; use `--reload-include` for extensions outside the default set.
