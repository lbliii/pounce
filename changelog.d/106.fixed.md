Subinterpreter worker mode no longer leaks the parent-side listener file descriptor across abnormal crash/respawn and reload cycles. The supervisor dups the listener FD per worker and passes it to the subinterpreter, which rebuilds a socket from it; previously the FD was only released on the clean drain path, so a worker that failed before serving (bad app import, `start_server` error, or a `worker_startup_failure='shutdown'` startup hook) or an old generation force-stopped during a graceful reload would leak that descriptor. The bootstrap now closes its reconstructed socket in a `finally` on every exit path and signals `STATUS_FD_CLOSED`, and the supervisor tracks the dup'd FD on each worker handle and reclaims orphaned descriptors before respawning a crashed worker and on the generational swap — with a self-close signal guard to avoid double-closing an FD value the OS may have reassigned. Thread and process worker modes are unaffected.
