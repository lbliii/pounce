OpenTelemetry request spans now use low-cardinality span names (the HTTP method, or `{method} {route}` when a route template is provided) instead of the raw request path, and emit stable OTel HTTP semantic-convention attributes (`http.request.method`, `url.path`, `url.scheme`, `server.address`, `server.port`, `http.response.status_code`, `http.response.body.size`) in place of the deprecated pre-1.20 names.
