Static file serving no longer crashes the worker with an uncaught `BlockingIOError` (EAGAIN) when a slow or disconnecting client fills the kernel send buffer mid-transfer. The zero-copy sendfile path now uses `loop.sendfile()`, which handles non-blocking-socket back-pressure through the selector instead of a raw `os.sendfile` loop in an executor thread. Client disconnects are treated as a clean abort rather than a 500.
